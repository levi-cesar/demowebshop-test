Casos de Teste – Demo Web Shop

Disciplina: Automação de Testes Ágeis  |  Ferramentas: Selenium WebDriver + Python

Aplicação sob teste: https://demowebshop.tricentis.com/

Instruções

  • O projeto deverá ser implementado em grupo.
  • Utilizar o padrão de projeto Page Objects.
  • Implementar no mínimo 3 testes por pessoa.
  • Implementar os testes usando Python + Selenium.
  • Serão avaliados:
    • Funcionamento correto dos testes;
    • Qualidade dos testes criados;
    • Qualidade do código implementado;
    • Boas práticas de programação.
  • Estarei disponível para dúvidas e suporte.

Dicas

  • Todos os casos são executados sem login (visitante), exceto quando a pré-condição diz outra coisa.
  • O ambiente é público e compartilhado: outras pessoas alteram os dados. Gere dados únicos (por exemplo, e-mail com timestamp) e não dependa de registros criados por terceiros.
  • Cada teste deve ser independente: crie os dados de que precisa na pré-condição (setup). O carrinho, a lista de desejos, a lista de comparação e os produtos vistos ficam guardados em cookies. Abra um navegador novo para cada teste para começar com essas listas vazias.
  • Use esperas explícitas (WebDriverWait + expected_conditions). Evite time.sleep().
  • Várias ações (adicionar ao carrinho, à lista de desejos etc.) mostram uma barra de notificação no topo da página (#bar-notification), que some em poucos segundos. Valide a mensagem logo após a ação.
  • Neste site, os campos de seleção (por exemplo, Sort by e Country) são <select> nativos. Você pode usar a classe Select do Selenium.
